## Tech Debt (Accepted Deviations)

### Phase 5: Navigation Overhaul (4 items)

These were identified during verification and accepted by the user as design decisions:

1. **Menu slide-down animation** — Overlay uses opacity/fade transition instead of translate-y slide-down as originally specified. Cosmetic only; navigation works correctly.

2. **Menu full-screen coverage** — Overlay missing `bottom-0` class, may not extend to absolute bottom of viewport. Navigation links are still accessible and usable.

3. **Menu background color** — Overlay uses bg-foreground (black) instead of bg-background (dusty pink). User accepted the dark overlay as a valid design choice.

4. **Focus trap completeness** — Inert attribute only applied to main element, not footer. Footer social links remain technically reachable via Tab when menu is open. Minor a11y gap.

**Total:** 4 items across 1 phase. All cosmetic or minor. No blockers.
