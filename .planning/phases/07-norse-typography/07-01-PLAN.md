  <action>
1. **Convert fonts to WOFF2:**
   - Install the npm package `@hayes0724/web-font-converter` as a dev dependency (or use npx)
   - Convert `fonts/norse/Norse.otf` to `public/fonts/Norse-Regular.woff2`
   - Convert `fonts/norse/Norse-Bold.otf` to `public/fonts/Norse-Bold.woff2`
   - If the npm converter fails, use an alternative approach: try `npx otf2woff2` or use a Node.js script with the `wawoff2` package to convert programmatically
   - Verify both WOFF2 files exist and are smaller than source OTFs (expect ~15-20KB each)
   - Create the `public/fonts/` directory if it does not exist

2. **Replace Space Grotesk with Norse in fonts.ts:**
   - Remove the `Space_Grotesk` import from `next/font/google`
   - Import `localFont` from `next/font/local`
   - Keep the `Inter` import from `next/font/google` unchanged
   - Define the Norse font using `localFont()`:
     ```typescript
     import localFont from 'next/font/local'
     import { Inter } from 'next/font/google'

     export const norse = localFont({
       src: [
         { path: '../../public/fonts/Norse-Regular.woff2', weight: '400', style: 'normal' },
         { path: '../../public/fonts/Norse-Bold.woff2', weight: '700', style: 'normal' },
       ],
       variable: '--font-display',
       display: 'swap',
       adjustFontFallback: 'Arial',
       fallback: ['Arial', 'Helvetica Neue', 'sans-serif'],
     })
     ```
   - The `variable: '--font-display'` ensures ALL existing `font-display` usage automatically picks up Norse
   - `adjustFontFallback: 'Arial'` provides automatic CLS protection via metric-adjusted fallback
   - `display: 'swap'` prevents invisible text during load

3. **Update layout.tsx import:**
   - Change `import { spaceGrotesk, inter } from "@/lib/fonts"` to `import { norse, inter } from "@/lib/fonts"`
   - Change `${spaceGrotesk.variable}` to `${norse.variable}` in the html className
   - No other changes needed -- the CSS variable name `--font-display` stays the same
  </action>
