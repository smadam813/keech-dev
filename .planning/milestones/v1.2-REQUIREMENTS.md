## v1.2 Requirements

Requirements for milestone v1.2 Norse Identity. Each maps to roadmap phases.

### Typography

- [x] **TYPO-01**: User sees Norse font (Joel Carrouche) as the display font for all headings, site name, and navigation text — Bold weight sitewide
- [x] **TYPO-02**: Font files are served in WOFF2 format for optimal loading performance — 23KB Regular, 23KB Bold
- [x] **TYPO-03**: Font loads without visible layout shift (CLS protected via adjustFontFallback: Arial)
- [x] **TYPO-04**: Norse font renders cleanly at all heading sizes with tuned letter-spacing and line-height
- [x] **TYPO-05**: Both Regular and Bold weights are available and used appropriately — Bold used everywhere for display

### Hero Image

- [x] **HERO-01**: Home page displays full-width Norse landscape hero image as background — full-viewport with object-cover
- [x] **HERO-02**: "keech.dev" renders as HTML text overlay in Norse font on top of the hero — centered with radial scrim
- [x] **HERO-03**: Text overlay meets WCAG AA contrast via scrim overlay — radial gradient (50%/35%/55%)
- [x] **HERO-04**: Hero image is optimized to <200KB for Core Web Vitals LCP compliance — 199KB WebP
- [x] **HERO-05**: Hero image scales responsively across mobile, tablet, and desktop — object-cover with position center

### Rune Decorations

- [x] **RUNE-01**: Reusable rune divider component replaces plain horizontal rules between sections — RuneDivider with Dagaz
- [x] **RUNE-02**: Blog and project list items use Elder Futhark runes as custom bullet markers — Ansuz (blog), Kenaz (projects)
- [x] **RUNE-03**: Navigation items display small rune accents — Othala, Ansuz, Kenaz, Mannaz prefixes
- [ ] **RUNE-04**: Subtle runic background texture patterns appear in page sections at low opacity — **User-rejected**: tested at 5%, 10%, 15% opacity; found distracting at all levels. Intentionally not implemented.
- [x] **RUNE-05**: All decorative rune elements use `aria-hidden` for accessibility compliance
- [x] **RUNE-06**: Rune elements render consistently across desktop and mobile browsers

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| CvltRvne font | Demo license only — not suitable for production |
| Futhark translation of content | Decorative use only — translating actual text would hurt readability |
| Animated rune particle effects | Too heavy, breaks neobrutalist restraint principle |
| Dark/light theme toggle | Cohesive single aesthetic is core to vision |
| Additional rune fonts | Norse font covers both Latin and Runic Unicode — one font is sufficient |
