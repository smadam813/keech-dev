# Phase 17 Plan 01: CSS Variables Syntax Highlighting Theme

## Objective

Migrate syntax highlighting from Shiki's bundled `github-dark-dimmed` theme to `createCssVariablesTheme()`, with token color CSS variables defined in `globals.css` alongside other design tokens. Set `keepBackground: false` so code block background is explicitly controlled via CSS.

## Context

- @velite.config.ts -- current rehype-pretty-code config with `theme: 'github-dark-dimmed'` and `keepBackground: true`
- @src/app/globals.css -- CSS-first design tokens, code block styles
- @src/proxy.ts -- CSP with `style-src 'self' 'unsafe-inline'`

## Tasks

### Task 1: Create CSS variables theme and update Velite config
type="auto"

**Do:**
1. In `velite.config.ts`, import `createCssVariablesTheme` from `shiki`
2. Create a CSS variables theme with `variablePrefix: '--shiki-'`
3. Replace `theme: 'github-dark-dimmed'` with the CSS variables theme
4. Set `keepBackground: false` so background is CSS-controlled

**Done when:** `velite.config.ts` uses `createCssVariablesTheme()` instead of `'github-dark-dimmed'`, and `keepBackground` is `false`.

### Task 2: Define token color variables in globals.css
type="auto"

**Do:**
1. Add Shiki token color CSS variables to `globals.css` in a dedicated code theme section
2. Map values from `github-dark-dimmed` theme colors to the `--shiki-*` CSS custom properties
3. Set `--shiki-background` explicitly for code block background
4. Set `--shiki-foreground` for default text color
5. Apply `background-color: var(--shiki-background)` on `figure[data-rehype-pretty-code-figure] pre`
6. Apply `color: var(--shiki-foreground)` on code elements

**Done when:** Token color variables are defined in `globals.css` and code blocks use CSS variables for background and text colors.

### Task 3: Build and verify
type="auto"

**Do:**
1. Run `npm run velite` to regenerate content with CSS variables theme
2. Run `npm run build` to verify full build succeeds
3. Run `npm run test` to verify existing tests pass
4. Run `npm run lint` to verify no new lint errors

**Done when:** Build succeeds, tests pass, lint clean.

## Verification

- [ ] Code block background set via CSS variable, `keepBackground: false` (SYN-03)
