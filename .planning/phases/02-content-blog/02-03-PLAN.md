# Phase 02 Plan 03: Blog Layout Width Fix

**Goal:** Expand blog post layout to better utilize horizontal space, aligning TOC with nav edge

**Source:** UAT gap closure (Test 6 - Prose Typography)

## Context

The blog post page has unused horizontal space because:
1. Container is `max-w-5xl` (1024px)
2. Prose uses `max-width: 65ch` (~585px) leaving ~93px unused
3. User wants TOC to align with "About" nav item edge

## Tasks

### Task 1: Expand blog layout width

**Files to modify:**
- `src/app/blog/[slug]/page.tsx` - Increase container width
- `src/components/layout/header.tsx` - Match container width for alignment

**Changes:**

1. In `src/app/blog/[slug]/page.tsx`:
   - Change `max-w-5xl` to `max-w-6xl` on the article container
   - This gives 1152px max instead of 1024px

2. In `src/components/layout/header.tsx`:
   - Change `max-w-5xl` to `max-w-6xl` on the header inner div
   - Ensures header nav aligns with blog content edges

3. In `src/app/globals.css`:
   - Remove `max-width: 65ch` from `.prose` class
   - The container and grid will handle width constraints
   - Prose content will expand to fill available space

**Verification:**
- Blog post content expands to use more horizontal space
- TOC aligns closer to "About" nav item edge
- Text remains readable (line length still reasonable due to grid)
- Header and content edges align on desktop

**Commit:** `fix(02): expand blog layout width for better space utilization`
