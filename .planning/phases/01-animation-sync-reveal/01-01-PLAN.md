<task type="auto">
  <name>Task 2: Convert hero.tsx to client component with load-gated reveal</name>
  <files>src/components/hero.tsx</files>
  <action>
Rewrite `src/components/hero.tsx` as a `'use client'` component with the following structure. Use `cn` from `@/lib/utils` for conditional class composition.

**Imports:**
```typescript
'use client'

import { useRef, useState, useEffect, useCallback } from 'react'
import Image from 'next/image'
import heroImage from '../../public/images/hero.webp'
import { cn } from '@/lib/utils'
```

**State and refs:**
- `imgRef = useRef<HTMLImageElement>(null)` -- ref to the Next.js Image underlying `<img>` element
- `imageLoaded: boolean` (useState, default false) -- whether the hero image has loaded and decoded
- `revealStage: 'loading' | 'bg-reveal' | 'text-reveal'` (useState, default 'loading') -- current stage of the two-beat sequence
- `hasPlayedRef = useRef(false)` -- guard to prevent re-animation on re-renders/tab switches (RVEAL-02)
- `prefersReducedMotion: boolean` (useState, default false) -- JS-level reduced-motion detection

**Image load detection (dual-path per SYNC-02):**

Path 1 -- `handleLoad` callback (useCallback):
```typescript
const handleLoad = useCallback(() => {
  setImageLoaded(true)
}, [])
```
Pass this as `onLoad={handleLoad}` to the Next.js Image component. Handles fresh image loads.

Path 2 -- `useEffect` on mount to check `img.complete`:
```typescript
useEffect(() => {
  if (imgRef.current?.complete && imgRef.current.naturalWidth > 0) {
    setImageLoaded(true)
  }
}, [])
```
Handles cached images and bfcache restores where `onLoad` may have already fired before React hydration.

**Reduced-motion detection (SYNC-03):**

```typescript
useEffect(() => {
  const mq = window.matchMedia('(prefers-reduced-motion: reduce)')
  setPrefersReducedMotion(mq.matches)

  const handler = () => setPrefersReducedMotion(mq.matches)
  mq.addEventListener('change', handler)
  return () => mq.removeEventListener('change', handler)
}, [])
```

This mirrors the pattern in `scroll-reveal.tsx` but adds a live toggle listener. Phase 2 will need the `prefersReducedMotion` state for glow animations.

**Reveal sequence orchestration (RVEAL-01, RVEAL-02):**

```typescript
useEffect(() => {
  if (!imageLoaded || hasPlayedRef.current) return
  hasPlayedRef.current = true

  if (prefersReducedMotion) {
    // Skip animation entirely -- CSS handles visibility via reduced-motion overrides
    setRevealStage('text-reveal')
    return
  }

  // Beat 1: Background blur-to-sharp (immediate)
  setRevealStage('bg-reveal')

  // Beat 2: Text fade-up (after blur transition + pause)
  // 350ms blur transition + 250ms pause = 600ms delay
  const timer = setTimeout(() => {
    setRevealStage('text-reveal')
  }, 600)

  return () => clearTimeout(timer)
}, [imageLoaded, prefersReducedMotion])
```

The `hasPlayedRef` guard ensures the sequence plays only once per component mount (navigation). On re-renders or tab switches, the guard prevents replay. On new navigation (component unmount + remount), the ref resets.

**JSX structure:**

Keep the same HTML structure as the current hero, but apply conditional classes based on `revealStage`:

```tsx
<section className="relative flex-1 flex items-center justify-center min-h-[calc(100svh-4rem)] overflow-hidden">
  {/* Background image with load-gated blur reveal */}
  <Image
    ref={imgRef}
    src={heroImage}
    alt=""
    fill
    sizes="100vw"
    preload
    placeholder="blur"
    className={cn(
      'object-cover',
      revealStage === 'loading' && 'hero-bg',
      revealStage === 'bg-reveal' && 'hero-bg hero-bg--revealed',
      // After text-reveal stage, remove blur classes entirely (clean final state)
    )}
    quality={80}
    onLoad={handleLoad}
  />

  {/* Dark gradient scrim for WCAG AA text contrast */}
  <div
    className="absolute inset-0 pointer-events-none"
    style={{
      background: 'radial-gradient(ellipse at center, rgba(0,0,0,0.5) 0%, rgba(0,0,0,0.35) 50%, rgba(0,0,0,0.55) 100%)'
    }}
  />

  {/* Centered text overlay with gated animation */}
  <div className={cn(
    'relative z-10 text-center',
    revealStage !== 'text-reveal' && 'hero-text--hidden',
    revealStage === 'text-reveal' && !prefersReducedMotion && 'hero-text--reveal',
  )}>
    <h1 className="font-display font-bold text-6xl sm:text-7xl md:text-8xl lg:text-9xl tracking-tight text-white">
      keech
      <span className="text-accent-light">.dev</span>
    </h1>
  </div>
</section>
```

Key class logic:
- **Loading stage:** Image has `hero-bg` (blurred). Text has `hero-text--hidden` (opacity 0).
- **bg-reveal stage:** Image gets `hero-bg hero-bg--revealed` (blur transitions to 0). Text still `hero-text--hidden`.
- **text-reveal stage:** Image blur classes removed (clean final state, no lingering `will-change` or `filter`). Text gets `hero-text--reveal` animation class (unless reduced-motion is active, in which case just remove `hero-text--hidden` so it appears instantly).
- **Reduced-motion:** When active, the CSS `@media (prefers-reduced-motion)` rules in globals.css override `hero-bg` (no blur), `hero-text--hidden` (opacity 1), and `hero-text--reveal` (no animation). The JS guard skips the setTimeout delay entirely.

**Important implementation notes:**
- Remove the `animate-on-load` class from the text overlay div. It is replaced by the new gated `hero-text--reveal` class.
- The `ref` prop on Next.js Image in v16 forwards directly to the underlying `<img>` element, so `useRef<HTMLImageElement>` is correct. If TypeScript errors occur, check the Next.js Image type and adjust accordingly.
- Do NOT add any new files. All logic goes in `hero.tsx`.
- Keep the exact same visual structure and element hierarchy. Only the classes and component directive change.
