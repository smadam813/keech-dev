That is the ONLY change to this file. The grid layout with TOC sidebar, header structure, and all content remain exactly as-is. The TOC sidebar is `hidden lg:block` so it only appears at 1024px+ viewports, which is wider than the 896px container -- this will work fine.

**Project detail (`src/app/projects/[slug]/page.tsx`):**

Line 51: Change the `<article>` class from `flex-1 container mx-auto max-w-3xl px-6 py-8` to `mx-auto max-w-4xl px-6 pt-12 pb-16`.

Changes: remove `flex-1` (root layout handles footer push), remove `container` (using max-w-* directly), change `max-w-3xl` to `max-w-4xl`, change `py-8` to `pt-12 pb-16`.

Everything else in this file stays the same -- back link, header with title/description/tech badges/action buttons, optional screenshot, MDX body content.

**About page (`src/app/about/page.tsx`):**

Line 11: Change `<main className="flex-1 max-w-3xl mx-auto px-6 py-12">` to `<section className="mx-auto max-w-4xl px-6 pt-12 pb-16">`.

Changes: `<main>` becomes `<section>` (fixes nested main), remove `flex-1` (root layout handles footer push), change `max-w-3xl` to `max-w-4xl`, change `py-12` to `pt-12 pb-16`.

Also change the closing tag on the last line from `</main>` to `</section>`.

Everything else stays the same -- photo section, bio section, resume button.

**Why removing flex-1 is safe:** The root layout (`layout.tsx` line 49) has `<main className="flex-1 flex flex-col pt-16">`. The `flex-1` on the root `<main>` already ensures it stretches to fill available space, pushing the footer to the bottom. Individual pages do not need their own `flex-1`. The home page (`page.tsx`) still has `flex-1` on its wrapper to vertically center content within the root main -- that is a different use case and should NOT be changed.
