## Overview

This portfolio site serves as my home on the web. Built with Next.js and styled with a distinctive neobrutalist design system, it showcases my projects and writing in a memorable cosmic-themed environment. The design draws inspiration from retro-futuristic aesthetics with dusty pinks, deep teals, and bold black borders.

## Technical Approach

The site uses Tailwind CSS v4's CSS-first theming approach, with design tokens defined in a `@theme` block rather than a JavaScript config file. Content is managed through MDX files processed by Velite, providing type-safe content collections for both blog posts and projects.

Code blocks feature syntax highlighting with a custom theme, line numbers, and copy buttons. The typography is optimized for long-form reading with Space Grotesk for headings and Inter for body text.

## Outcome

The result is a distinctive personal site that stands apart from typical developer portfolios. The neobrutalist aesthetic creates a memorable visual identity while maintaining excellent readability and accessibility. The site serves as both a showcase of my work and a playground for exploring modern web development patterns.
