Deploy the site to Vercel:

1. Install Vercel CLI if not already installed:
   ```bash
   npm install -g vercel
   ```

2. Login to Vercel (if not already authenticated):
   ```bash
   vercel login
   ```
   - Follow browser authentication flow if prompted

3. Deploy to Vercel:
   ```bash
   vercel --yes
   ```
   - This creates a new project and deploys
   - Note the deployment URL (e.g., keech-dev-xxx.vercel.app)

4. For production deployment (if preview works):
   ```bash
   vercel --prod
   ```

5. Record the production URL for verification checkpoint

Note: If Vercel CLI auth fails, this becomes an auth gate. Claude will report the error and user will need to authenticate manually, then Claude retries.
