4. **`computeGlowPositions()` function** — takes the RUNE_GLOWS array and container width/height. Returns an array of `{ left: string, top: string, visible: boolean }` using the object-cover position mapping formula:
   - `scale = Math.max(containerW / IMG_W, containerH / IMG_H)`
   - `renderedW = IMG_W * scale`, `renderedH = IMG_H * scale`
   - `offsetX = (renderedW - containerW) / 2`, `offsetY = (renderedH - containerH) / 2`
   - For each rune: `cx = imgX * renderedW - offsetX`, `cy = imgY * renderedH - offsetY`
   - `visible = cx > -50 && cx < containerW + 50 && cy > -50 && cy < containerH + 50`
   - Return `{ left: '${cx}px', top: '${cy}px', visible }`

5. **`getEntranceDelay()` function** — takes index and total count, returns delay string in ms. Uses power curve (exponent 1.5) over ~3000ms total cascade:
   ```typescript
   function getEntranceDelay(index: number, total: number): string {
     const totalCascade = 3000
     const fraction = total > 1 ? index / (total - 1) : 0
     return `${Math.round(totalCascade * Math.pow(fraction, 1.5))}ms`
   }
   ```

Export: `RUNE_GLOWS`, `computeGlowPositions`, `getEntranceDelay`, and the `RuneGlow` type.

3. **Add `glowsActive` state:**


4. **Add `positions` state** — array of computed glow positions:
   ```typescript
   const [positions, setPositions] = useState<Array<{ left: string; top: string; visible: boolean }>>([])
   ```

5. **Add glowsActive trigger effect** — activates glows after text reveal completes. The text reveal animation is 500ms (heroTextReveal in globals.css). Wait for it to finish before starting the glow cascade:
   ```typescript
   useEffect(() => {
     if (revealStage !== 'text-reveal' || prefersReducedMotion) return
     const timer = setTimeout(() => setGlowsActive(true), 500)
     return () => clearTimeout(timer)
   }, [revealStage, prefersReducedMotion])
   ```

6. **Add ResizeObserver effect** — observes the section element and recalculates glow positions when it resizes. Use `contentRect` from the ResizeObserver entry to avoid layout thrashing:
   ```typescript
   useEffect(() => {
     const section = sectionRef.current
     if (!section) return

     const update = (w: number, h: number) => {
       setPositions(computeGlowPositions(RUNE_GLOWS, w, h))
     }

     // Initial calculation
     const rect = section.getBoundingClientRect()
     update(rect.width, rect.height)

     const ro = new ResizeObserver((entries) => {
       const entry = entries[0]
       if (entry) {
         const { width, height } = entry.contentRect
         update(width, height)
       }
     })
     ro.observe(section)
     return () => ro.disconnect()
   }, [])
   ```

7. **Render glow overlay divs** — add a glow container div AFTER the gradient scrim div and BEFORE the text overlay div (so glows appear behind text but in front of the scrim). The container needs `absolute inset-0 overflow-hidden` to clip glows that fall outside the visible area:

   ```tsx
   {/* Rune glow overlays */}
   <div className="absolute inset-0 overflow-hidden pointer-events-none">
     {glowsActive && positions.length > 0 && RUNE_GLOWS.map((rune, i) => {
       const pos = positions[i]
       if (!pos?.visible) return null
       return (
         <div
           key={rune.id}
           className={cn(
             'rune-glow',
             `rune-glow--${rune.color}`,
             glowsActive && 'rune-glow--active',
           )}
           style={{
             left: pos.left,
             top: pos.top,
             width: `${rune.size}rem`,
             height: `${rune.size}rem`,
             '--entrance-delay': getEntranceDelay(i, RUNE_GLOWS.length),
             '--breath-duration': rune.breathDuration,
           } as React.CSSProperties}
         />
       )
     })}
   </div>
   ```

**Important implementation notes:**
- Do NOT add `mix-blend-mode` to glow elements (breaks GPU compositing in Chrome).
- The glow container div must have `pointer-events: none` so it doesn't block interaction.
- The `overflow-hidden` on the glow container clips edge runes that are positioned outside the visible area on narrow viewports.
- CSS custom properties `--entrance-delay` and `--breath-duration` are set as inline styles per element, consumed by the CSS classes defined in Task 1.
- The `as React.CSSProperties` cast is needed because React's type definition doesn't include CSS custom properties by default.
