  <name>Task 2: Create Hero component, update home page, add CSS variable</name>
  <files>src/components/hero.tsx, src/app/page.tsx, src/app/globals.css</files>
  <action>
    1. Add a `--color-accent-light` CSS variable to `globals.css` inside the existing `@theme` block. Value: `#4FBFBF` (lighter teal that passes WCAG AA-large against hero image with scrim, per research contrast measurements). This variable is for use on dark backgrounds where the standard `--color-accent` (#2D8B8B) would fail contrast.

    2. Create `src/components/hero.tsx` as a **server component** (no 'use client' needed). Implementation:

       ```tsx
       import Image from 'next/image'
       import heroImage from '../../public/images/hero.webp'

       export function Hero() {
         return (
           <section className="relative flex-1 flex items-center justify-center min-h-[calc(100svh-4rem)] overflow-hidden">
             {/* Background image with automatic blur placeholder from static import */}
             <Image
               src={heroImage}
               alt=""
               fill
               sizes="100vw"
               preload
               placeholder="blur"
               className="object-cover"
               quality={80}
             />

             {/* Dark gradient scrim for WCAG AA text contrast */}
             <div
               className="absolute inset-0 pointer-events-none"
               style={{
                 background: 'radial-gradient(ellipse at center, rgba(0,0,0,0.5) 0%, rgba(0,0,0,0.35) 50%, rgba(0,0,0,0.55) 100%)'
               }}
             />

             {/* Centered text overlay */}
             <div className="relative z-10 text-center animate-on-load">
               <h1 className="font-display font-bold text-6xl sm:text-7xl md:text-8xl lg:text-9xl tracking-tight text-white">
                 keech
                 <span className="text-accent-light">.dev</span>
               </h1>
             </div>
           </section>
         )
       }
       ```

       Key design decisions (per user locked decisions + research):
       - **Dead center, bold, immediate impact**: flex items-center justify-center, font-bold, text-6xl scaling up to lg:text-9xl
       - **No tagline or subtitle**: Only "keech.dev" text, nothing else
       - **Text IS the hero moment**: Responsive sizes from 60px mobile to 128px desktop (matches existing page sizes)
       - **Dark gradient scrim**: Radial gradient centered at 50% opacity, lighter at middle ring (35%), darker at edges (55%) — creates natural vignette that frames the composition without flattening the image
       - **WCAG compliance**: White text passes AA easily (7.47:1 even at brightest spots with scrim). Teal `.dev` uses `--color-accent-light` (#4FBFBF) which passes AA-large (3.39:1 at worst case, 7.60:1 at typical center)
       - **Viewport behavior**: `min-h-[calc(100svh-4rem)]` fills viewport minus the 4rem (64px) fixed header. Uses `svh` not `vh` to avoid mobile address bar issues
       - **`alt=""`**: Image is decorative (the content is the text overlay), empty alt is correct for accessibility
       - **`preload`**: This is the LCP element, must be preloaded (not `priority` which is deprecated in Next.js 16)

    3. Update `src/app/page.tsx` to render the Hero component instead of the current plain text:

