# Phase 3: Projects & About - Context

**Gathered:** 2026-02-01
**Status:** Ready for planning

<domain>
## Phase Boundary

Deliver project portfolio showcase and about page. Visitors can explore projects with visual cards, view individual project details with descriptions and links, and learn about the site owner through a professional bio with photo and social links. Resume download available from about page.

</domain>

<decisions>
## Implementation Decisions

### Project Card Design
- Optional screenshot/thumbnail — show image if available, graceful fallback without
- Standard info density: title, short description, tech stack badges
- Tech badges on cards — Claude's discretion on icon-only vs text chips

### Project Detail Pages
- Medium write-up depth — overview, challenges, outcome (2-3 paragraphs)
- Screenshots optional — include if available, fine without
- Flexible links per project — show GitHub, live demo, or whatever exists for each
- Project navigation — Claude's discretion on related/next-prev vs back-to-list only

### Project Organization
- Categories (side project, professional, open source) — Claude's discretion based on content volume

### About Page
- Professional, third-person tone for bio
- Professional headshot photo prominently featured
- Sections beyond bio — Claude's discretion (skills, timeline, or just social links)
- Social link presentation — Claude's discretion (match footer or different treatment)

### Resume Handling
- Resume access from about page only (not header or footer)
- Format — Claude's discretion (PDF download vs inline preview)
- Placeholder UI for now — actual PDF file to be provided later
- Contact method — Claude's discretion (email, form, or social links only)

### Claude's Discretion
- Tech badge styling (icons vs text chips)
- Project navigation pattern (related projects vs back-to-list)
- Whether to categorize projects
- About page sections beyond bio
- Social link visual treatment
- Resume delivery mechanism (download vs preview)
- Contact method (if any beyond social links)

</decisions>
