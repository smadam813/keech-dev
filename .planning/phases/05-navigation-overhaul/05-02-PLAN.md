<task type="auto">
  <name>Task 1: Fix footer safe-area padding</name>
  <files>src/components/layout/footer.tsx</files>
  <action>
    Update the footer padding to remove the bottom nav compensation hack.

    **Current (has bottom nav padding hack):**
    ```
    className="bg-foreground text-background pt-8 pb-[calc(6rem+env(safe-area-inset-bottom))] md:py-8 mt-auto"
    ```
    The `6rem` was the height of the bottom nav bar. The `md:py-8` override was because desktop never had the bottom nav.

    **Change to:**
    ```
    className="bg-foreground text-background py-8 pb-[calc(2rem+env(safe-area-inset-bottom))] mt-auto"
    ```

    Rationale:
    - `py-8` (2rem) gives consistent vertical padding on all viewports
    - `pb-[calc(2rem+env(safe-area-inset-bottom))]` overrides the bottom padding to add safe-area inset on top of the standard 2rem. On non-notch devices, env(safe-area-inset-bottom) is 0, so it equals py-8. On notch devices, it adds the home indicator spacing.
    - No more `md:` breakpoint override needed -- padding is the same everywhere
    - Footer content stays exactly as-is (LOCKED decision): copyright text + social icon links

    Do NOT change any footer content, links, or structure. Only modify the className padding values.
  </action>
  <verify>
    Run `npm run build` to confirm no errors. Verify footer.tsx no longer contains `6rem` or `pb-20` or the old padding hack. Verify it contains `safe-area-inset-bottom`.
  </verify>
  <done>
    Footer has clean safe-area padding without the bottom nav compensation hack. On notch devices, the footer sits at the natural page bottom with correct spacing. On non-notch devices, padding is a standard 2rem.
  </done>
</task>
