<task type="auto">
  <name>Task 2: Create FilterBar component</name>
  <files>src/components/ui/filter-bar.tsx</files>
  <action>
Create a new `'use client'` component at `src/components/ui/filter-bar.tsx`. This is a controlled component — it receives state via props and calls callbacks to change it. It does NOT own filter state (Phase 7 will manage state and URL persistence).

**Interface:**
```typescript
interface FilterBarProps {
  items: string[]
  activeItems: Set<string>
  onToggle: (item: string) => void
  onClear: () => void
  renderChip: (props: { item: string; active: boolean; onToggle: () => void }) => ReactNode
  label?: string
}
```

**Implementation:**
- Add `'use client'` directive at top of file (required because it receives function props).
- Import `type ReactNode` from `react`.
- Export named function `FilterBar`.
- `label` defaults to `'Filters'`.
- Compute `hasActive = activeItems.size > 0`.
- Render outer `<div role="group" aria-label={label}>` with `className="mb-6"`.
- Inner `<div className="flex flex-wrap gap-2 items-center">` contains:
  - Map over `items`, calling `renderChip({ item, active: activeItems.has(item), onToggle: () => onToggle(item) })` for each.
  - Conditionally render "Clear all" button when `hasActive` is true: `<button type="button" onClick={onClear} className="px-2 py-0.5 text-xs font-mono font-bold text-accent hover:text-accent-hover transition-colors underline underline-offset-2">Clear all</button>`.
- No label text above chips — the chips are self-explanatory in context.
- Wrapping rows via `flex-wrap` — with 7 blog tags and 8 project stack items, chips fit on one row on desktop and wrap naturally on mobile. No horizontal scroll needed.

**Why renderChip prop:** Blog pages will pass `<TagChip>` and project pages will pass `<TechBadge>` without FilterBar knowing about either component. This keeps FilterBar generic without premature abstraction.
