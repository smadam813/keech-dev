**Create src/hooks/use-filtered-list.ts** (per D-07, QUAL-03):

Create the `src/hooks/` directory if it doesn't exist.

```typescript
'use client'

import { useSearchParams, usePathname } from 'next/navigation'
import { useCallback, useEffect, useMemo, useRef, useState } from 'react'

interface UseFilteredListOptions<T> {
  items: T[]
  allFilterValues: string[]
  getItemValues: (item: T) => string[]
  paramName: string
}

interface UseFilteredListResult<T> {
  filteredItems: T[]
  activeFilters: Set<string>
  isFiltering: boolean
  isTransitioning: boolean
  filterCounts: Record<string, number>
  handleToggle: (value: string) => void
  handleClear: () => void
}

export function useFilteredList<T>(options: UseFilteredListOptions<T>): UseFilteredListResult<T>
```

Implementation extracts the EXACT logic from `filtered-post-list.tsx`:
- Read `paramName` from URL search params, split by comma, filter Boolean, create Set
- AND-filter: `items.filter(item => [...activeFilters].every(v => getItemValues(item).includes(v)))`
- Static counts: for each value in `allFilterValues`, count items containing it
- URL writing via `window.history.replaceState` using `URLSearchParams` -- same pattern as current code
- Transition state: `isTransitioning` with 150ms timeout, skip initial render via `useRef(true)`
- `handleToggle(value)`: add/remove from Set, update URL
- `handleClear()`: empty Set, update URL

This is a direct extraction -- no logic changes, just parameterized. The `getItemValues` accessor replaces hardcoded `post.tags` / `project.stack` access.
