**Create src/hooks/use-hero-animation.ts** (per D-11, QUAL-05):

Extract lines 26-84 of hero.tsx into a hook. The hook accepts refs and returns animation state.

```typescript
'use client'

import { useRef, useState, useEffect, useCallback, type RefObject } from 'react'

type RevealStage = 'loading' | 'bg-reveal' | 'text-reveal'

interface UseHeroAnimationOptions {
  imgRef: RefObject<HTMLImageElement | null>
}

interface UseHeroAnimationResult {
  revealStage: RevealStage
  glowsActive: boolean
  prefersReducedMotion: boolean
  handleLoad: () => void
}

export function useHeroAnimation({ imgRef }: UseHeroAnimationOptions): UseHeroAnimationResult
```

Implementation (direct extraction from hero.tsx):
- `imageLoaded` state (internal, not exposed)
- `revealStage` state initialized to `'loading'`
- `hasPlayedRef` to prevent replay
- `prefersReducedMotion` state with matchMedia detection and change listener (lines 47-54)
- `handleLoad` callback that sets `imageLoaded = true` (line 35-37)
- `useEffect` checking `imgRef.current?.complete` on mount for cached images (lines 40-43) -- guard against `imgRef.current` being null
- Reveal sequence `useEffect` (lines 57-77): when imageLoaded and not played, if reduced motion skip to text-reveal, else bg-reveal then 600ms timeout to text-reveal
- Glow cascade `useEffect` (lines 80-84): when text-reveal and not reduced motion, 500ms timeout to `glowsActive = true`
- `glowsActive` state (default false)
