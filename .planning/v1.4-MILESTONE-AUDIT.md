## E2E Flows (3/3 complete)

### Flow 1: Individual Post Visit
User → `/blog/[slug]` (static) → ViewCounter mounts → localStorage pre-fill → POST `/api/views/[slug]` → Redis SET NX + conditional INCR → response → display formatted count → update cache.
**Failure path:** fetch silently catches → cached value or empty placeholder shown.
**Requirements touched:** INFRA-01–05, VIEW-01, VIEW-02, VIEW-04, UX-01, UX-02, UX-03

### Flow 2: Blog Listing Page
User → `/blog` (static) → ListingViewCounts mounts → localStorage pre-fill → GET `/api/views?slugs=...` → Redis mget batch → response → Context propagation → PostCardViewCount per card → formatted display.
**Failure path:** fetch silently catches → cached values or cards render without counts.
**Requirements touched:** INFRA-01, INFRA-05, VIEW-03, UX-01, UX-03

### Flow 3: Return Visit (Cached)
User returns → `useLayoutEffect` reads localStorage before paint → count renders immediately → POST/GET fires in background → updates displayed count if changed.
**Requirements touched:** UX-02 (no flash/CLS)

## Tech Debt (Minor — 3 items, no blockers)

### Phase 3: Infrastructure & API
- **Documentation gap:** SUMMARY setup instructions reference `UPSTASH_REDIS_REST_URL`/`TOKEN` but Vercel Marketplace provisions `KV_REST_API_URL`/`TOKEN`. SDK fallback handles this — not a code bug, but docs should be updated if onboarding others.

### Phase 5: Listing & Polish
- **Dead public export:** `useViewCount` exported from `listing-view-counts.tsx` but only consumed internally by `PostCardViewCount`. Minor API surface concern.
- **No URL encoding on batch slugs:** `slugs.join(',')` passed without `encodeURIComponent`. Safe given Velite's alphanumeric-and-hyphen slug constraints, but would break if slugs ever contained special characters.
