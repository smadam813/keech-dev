  <action>
Add animation system to globals.css with the following:

1. In the @theme block, add custom animation:
   - `--animate-fade-in-up: fadeInUp 0.5s ease-out forwards`

2. Add @keyframes fadeInUp:
   - from: opacity 0, translateY(20px)
   - to: opacity 1, translateY(0)

3. In @layer components, add scroll-reveal class:
   - Default state: opacity 1 (fallback for browsers without support)
   - @supports (animation-timeline: view()) block with:
     - animation: fadeInUp linear both
     - animation-timeline: view()
     - animation-range: entry 10% entry 90%
   - @media (prefers-reduced-motion: reduce) block:
     - animation: none !important
     - opacity: 1

4. Add motion-reduce utility for transitions:
   - @media (prefers-reduced-motion: reduce) .motion-reduce-safe { transition: none !important }

Only animate transform and opacity (never layout properties) to prevent CLS issues.
  </action>
