  <action>
Create `src/components/blog/view-counter.tsx` as a `'use client'` leaf component.

**Component specification:**

```typescript
'use client'

import { useEffect, useRef, useState } from 'react'
```

Interface: `ViewCounterProps { slug: string }`

**State:** `views: number | null` (null = loading), `hasFired: useRef<boolean>(false)` (StrictMode guard).

**useEffect (fires once on mount):**
1. Check `hasFired.current` — return early if true (prevents double-POST in React StrictMode dev mode)
2. Set `hasFired.current = true`
3. `fetch(\`/api/views/${slug}\`, { method: 'POST' })`
4. If response not ok, throw (triggers catch)
5. Parse JSON, call `setViews(data.views)`
6. Catch: fail silently — view count is non-critical UI. Leave `views` as null (shimmer stays visible; full degradation behavior is Phase 5 UX-03 scope, but the error path is established here)

**Render logic:**
- If `views === null`: render shimmer placeholder — `<span>` with classes: `inline-block w-16 h-5 rounded-sm bg-muted/20 animate-shimmer` and `aria-hidden="true"` (placeholder is decorative during loading)
- If `views !== null`: render `<span>{views.toLocaleString()} {views === 1 ? 'view' : 'views'}</span>`

**Design decisions (Claude's discretion per CONTEXT.md):**
- Shimmer style: hard-edge `rounded-sm` with `bg-muted/20` opacity pulse (fits neobrutalist palette)
- Transition from shimmer to number: instant (no fade — consistent with hard-edge aesthetic)
- Singular/plural: "1 view" / "N views" (natural English)
- Number formatting: `toLocaleString()` for locale-aware commas
- POST response: display returned count immediately (instant feedback, count is accurate)

Export as named export: `export function ViewCounter({ slug }: ViewCounterProps)`
