  <action>
In next.config.ts, update the script-src line in the cspHeader array from:

  "script-src 'self' 'unsafe-eval' https://va.vercel-scripts.com"

to:

  "script-src 'self' 'unsafe-eval' 'unsafe-inline' https://va.vercel-scripts.com"

This is the minimal fix. Next.js App Router requires inline scripts for:
- RSC flight data serialization
- Client component hydration bootstrapping
- Suspense boundary resolution

Do NOT switch to nonce-based CSP — Next.js middleware nonce injection is complex and fragile with App Router static generation. The site already uses 'unsafe-eval' for MDX `new Function()`, so adding 'unsafe-inline' does not meaningfully widen the attack surface.

Leave all other CSP directives and security headers unchanged.
