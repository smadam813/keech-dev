**Favicon SVG (per D-01, D-02, D-03):**
Create `src/app/icon.svg` — an SVG favicon featuring the Othala rune. Design:
- ViewBox: `0 0 32 32`
- Background: rounded rect with dusty rose fill `#E8B4B8` and `rx="4"`
- Othala rune rendered as SVG `<path>` elements (not `<text>`) for cross-browser reliability. The Othala rune shape is a diamond on top of two downward-spreading legs — draw it with bold strokes. Use `stroke="#2D8B8B"` (teal accent), `stroke-width="2.5"`, `fill="none"`, `stroke-linecap="round"`, `stroke-linejoin="round"`. Path should be roughly centered in the 32x32 viewbox.
- The Othala rune path: a diamond shape (top vertex ~16,4, right ~26,14, bottom ~16,22, left ~6,14) with two legs extending from the bottom vertex down and outward (to ~10,28 and ~22,28). Adjust proportions for visual balance.

**ICO favicon (per D-02 — MANDATORY):**
Create `src/app/icon.ico` for legacy browser compatibility. Next.js does NOT auto-generate ICO from SVG — this must be explicitly created. Steps:
1. Use sharp via npx to render the SVG to a 32x32 PNG buffer: `npx sharp-cli -i src/app/icon.svg -o /tmp/icon-32.png resize 32 32` OR use a Node.js one-liner with sharp: `node -e "const sharp = require('sharp'); sharp('src/app/icon.svg').resize(32,32).png().toFile('/tmp/icon-32.png')"`
2. Convert the 32x32 PNG to ICO format. Use `npx png-to-ico /tmp/icon-32.png > src/app/icon.ico` OR write a minimal Node.js script that wraps the PNG in ICO container format (ICO is just a header + embedded PNG).
3. If neither sharp nor png-to-ico is available, install temporarily: `npx -y png-to-ico /tmp/icon-32.png > src/app/icon.ico`
4. Verify the ICO file exists and has reasonable size (> 100 bytes).

**Apple Touch Icon (per D-02):**
Create `src/app/apple-icon.png` — a 180x180 PNG. Use the same design as the SVG favicon but rendered as a PNG. The executor should:
1. Create a simple script or use Node.js to generate a 180x180 PNG with the same dusty rose background and teal Othala rune, OR
2. Create the PNG manually using sharp or a similar tool available via npx.
The apple-icon should have NO transparency (iOS adds its own rounding) — use solid `#E8B4B8` background filling the entire 180x180 canvas.

**Inter Bold TTF for OG images:**
The Norse font is only available as WOFF2 which Satori cannot read. Per research recommendation, use Inter Bold for OG image text rendering.
1. Download Inter Bold TTF from Google Fonts CDN: `https://fonts.gstatic.com/s/inter/v18/UcCo3FwrK3iLTcviYwY.ttf` (Inter Bold 700)
2. Place at `src/assets/fonts/Inter-Bold.ttf`
3. This file will be loaded via `fetch(new URL('./path', import.meta.url)).then(res => res.arrayBuffer())` in OG image generators

If the Google Fonts URL doesn't work, download Inter from the npm package `@fontsource/inter` or fetch from another CDN. The key requirement is a `.ttf` file of Inter at weight 700.

```typescript
import { ImageResponse } from 'next/og'
import { posts } from '@/.velite'

export const alt = 'Blog post'
export const size = { width: 1200, height: 630 }
export const contentType = 'image/png'

export default async function Image({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params
  const post = posts.find(p => p.slug === slug)

  const interBold = await fetch(
    new URL('../../../assets/fonts/Inter-Bold.ttf', import.meta.url)
  ).then((res) => res.arrayBuffer())

  const title = post?.title ?? 'Blog Post'
  const date = post?.date
    ? new Date(post.date).toLocaleDateString('en-US', { year: 'numeric', month: 'long', day: 'numeric' })
    : ''

  return new ImageResponse(
    (
      <div style={{
        width: '100%',
        height: '100%',
        display: 'flex',
        flexDirection: 'column',
        justifyContent: 'center',
        alignItems: 'center',
        backgroundColor: '#E8B4B8',
        padding: '60px',
      }}>
        {/* Offset shadow layer */}
        <div style={{
          display: 'flex',
          position: 'absolute',
          top: '68px',
          left: '68px',
          width: '1072px',
          height: '502px',
          backgroundColor: '#000000',
        }} />
        {/* Card */}
        <div style={{
          display: 'flex',
          flexDirection: 'column',
          justifyContent: 'space-between',
          backgroundColor: '#F5E6E8',
          border: '4px solid #000000',
          padding: '48px',
          width: '1072px',
          height: '502px',
        }}>
          {/* Title area */}
          <div style={{
            display: 'flex',
            flexDirection: 'column',
          }}>
            <div style={{
              fontSize: title.length > 60 ? 36 : title.length > 40 ? 44 : 52,
              fontWeight: 700,
              fontFamily: 'Inter',
              color: '#000000',
              lineHeight: 1.2,
            }}>
              {title}
            </div>
            {date && (
              <div style={{
                fontSize: 22,
                fontFamily: 'Inter',
                fontWeight: 700,
                color: '#4A4A4A',
                marginTop: 16,
              }}>
                {date}
              </div>
            )}
          </div>
          {/* Footer with branding */}
          <div style={{
            display: 'flex',
            justifyContent: 'space-between',
            alignItems: 'center',
          }}>
            <div style={{
              fontSize: 24,
              fontWeight: 700,
              fontFamily: 'Inter',
              color: '#2D8B8B',
            }}>
              keech.dev
            </div>
            {/* Teal accent bar */}
            <div style={{
              width: '80px',
              height: '6px',
              backgroundColor: '#2D8B8B',
            }} />
          </div>
        </div>
      </div>
    ),
    {
      ...size,
      fonts: [
        { name: 'Inter', data: interBold, style: 'normal' as const, weight: 700 as const },
      ],
    }
  )
}

export function generateStaticParams() {
  return posts.map(post => ({ slug: post.slug }))
}
```
