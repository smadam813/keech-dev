# Milestone v1.2: Norse Identity

**Status:** SHIPPED 2026-02-08

## Overview

Deepened the Norse/runic aesthetic throughout the site with a runic display font, atmospheric hero image, and decorative Elder Futhark elements. ## Milestone Summary

**Key Decisions:**
- Norse font (Joel Carrouche) selected for both Latin and Runic Unicode coverage (freeware license)
- CvltRvne font excluded — demo license only, not production-suitable
- Bold weight for ALL Norse font display usage — Regular weight too thin at smaller heading sizes
- Static image import for hero enables automatic blurDataURL (no manual base64)
- Radial gradient scrim (50%/35%/55%) for natural vignette instead of linear gradient
- --color-accent-light (#4FBFBF) as separate variable for WCAG AA on dark backgrounds
- Next.js 16 qualities: [75, 80] config needed to prevent silent quality coercion
- Dagaz (dawn) as default divider rune; Ansuz (wisdom) for blog bullets; Kenaz (craft) for project bullets
- CSS ::before pseudo-element for rune bullets (zero JS, 100% browser support)
- NAV_RUNES lookup by href keeps nav data and rune data cleanly separated
- Context-aware prose bullets via .prose-projects CSS cascade
- Background texture removed — user found it distracting at all opacity levels tested

**Issues Resolved:**
- Space Grotesk replacement executed with zero breakage via preserved --font-display CSS variable
- Hero image optimized from 7MB PNG to 199KB WebP (97% reduction)
- Norse font Regular weight visibility issue resolved by switching to Bold everywhere

**Issues Deferred:**
- ESLint 9 + Next.js 16 FlatCompat layer circular JSON error — `next lint` non-functional (pre-existing)
- TYPO-03/TYPO-04 human browser verification at throttled 3G (low severity)

**Technical Debt Incurred:**
- RuneDivider component created but not yet integrated into page layouts (available for future use)
- BLOG_RUNES, PROJECT_RUNES, TEXTURE_RUNES exports orphaned in rune-config.ts (superseded by CSS approach)
- RUNE-04 background texture feature explored, implemented, and intentionally removed by user
