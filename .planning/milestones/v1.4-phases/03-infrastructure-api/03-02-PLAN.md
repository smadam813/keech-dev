**Current code (lines 39-46):**
```typescript
const p = redis.pipeline()

p.incr(`views:${slug}`)
const [dedupResult, viewCount] = await p.exec<[string | null, number]>()
```

**Replace with two-step logic:**

Step 1: Execute `redis.set()` with `{ ex: 86400, nx: true }` (SET NX — only sets if key does not exist). This returns `'OK'` if the key was newly set (first visit from this IP) or `null` if the key already exists (repeat visit).

Step 2: Branch on the result:
- If `dedupResult === 'OK'` (first visit): execute `redis.incr('views:${slug}')` to increment and get the new count. Return `{ slug, views: viewCount, deduplicated: false }`.
- If `dedupResult === null` (repeat visit): execute `redis.get<number>('views:${slug}')` to read current count without incrementing. Return `{ slug, views: currentViews ?? 0, deduplicated: true }`.

**Implementation:**
```typescript
// Step 1: Check/set dedup key (NX = only if not exists, 24h TTL)
const dedupResult = await redis.set(`dedup:${slug}:${ipHash}`, '1', { ex: 86400, nx: true })

if (dedupResult === 'OK') {
  // First visit from this IP within 24h — increment
  const viewCount = await redis.incr(`views:${slug}`)
  return Response.json({ slug, views: viewCount, deduplicated: false })
} else {
  // Repeat visit — return current count without incrementing
  const views = await redis.get<number>(`views:${slug}`) ?? 0
  return Response.json({ slug, views, deduplicated: true })
}
```
