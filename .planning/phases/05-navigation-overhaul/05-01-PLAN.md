  <action>
    Rewrite header.tsx as a 'use client' component. The single Header component handles both desktop and mobile navigation.

    **Structure:**
    - Add 'use client' directive at top
    - Import useState, useEffect, useCallback from react
    - Import usePathname from next/navigation
    - Import Link from next/link
    - Import Menu, X from lucide-react
    - Import cn from @/lib/utils
    - Keep the existing navItems array (Home, Blog, Projects, About)

    **Desktop behavior (md: and above):**
    - Keep existing desktop layout: fixed header with logo left, inline nav links right
    - The hamburger button is hidden at md: via `md:hidden`
    - Add active page indication on desktop nav links too (accent color, using same isActive logic as mobile)

    **Mobile behavior (below md:):**
    - Header is visible on mobile (remove the `hidden md:block` -- header should show on ALL viewports)
    - Desktop nav links hidden below md: via `hidden md:flex` on the nav element
    - Hamburger button visible below md: on the RIGHT side of the header (LOCKED decision)
    - Button has aria-expanded, aria-controls="mobile-menu", aria-label
    - Icon swaps between Menu and X based on isOpen state (NAV-08)

    **Menu overlay (NAV-05):**
    - Renders as a div below the header bar, INSIDE the header component
    - id="mobile-menu", role="dialog", aria-modal="true", aria-label="Navigation menu"
    - Position: fixed, top: 4rem (header height), left/right/bottom: 0
    - Background: bg-background (dusty pink, same as page)
    - Border: border-t-[3px] border-foreground (neobrutalist)
    - Hidden on md: via md:hidden
    - Animation: slide down from header (LOCKED decision) -- use CSS transform translate-y. When closed: -translate-y-full. When open: translate-y-0. Add transition-transform duration-300 ease-in-out.
    - When closed, also set invisible (Tailwind) to hide from screen readers and prevent interaction
    - When open, set visible

    **Navigation links inside overlay:**
    - Centered vertically and horizontally in the overlay
    - flex flex-col items-center justify-center h-full gap-8
    - Each link: font-display text-3xl font-bold
    - Active link: text-accent (teal) -- use same isActive logic from current mobile-nav.tsx
    - Inactive link: text-foreground with hover:text-accent transition-colors
    - On click, call setIsOpen(false) to close menu immediately (good UX for link taps)

    **Route change auto-close (NAV-06):**
    - useEffect watching pathname that calls setIsOpen(false)

    **Scroll lock (NAV-10):**
    - useEffect watching isOpen:
      - When opening: save window.scrollY, set document.body.style.position='fixed', top=-scrollY+'px', left='0', right='0', overflow='hidden'
      - When closing: read saved top value, clear all body styles, call window.scrollTo(0, parsedScrollY)
      - Cleanup function: clear all body styles on unmount
    - This is the iOS Safari-safe approach (position: fixed, NOT just overflow: hidden)

    **Focus management (NAV-09):**
    - useEffect watching isOpen:
      - When opening: set inert attribute on document.querySelector('main') and document.querySelector('footer')
      - When closing: remove inert attribute from both
      - Cleanup function: remove inert from both on unmount
    - This replaces manual Tab key interception -- inert handles everything natively

    **Escape key (NAV-09):**
    - useEffect that adds keydown listener for Escape when isOpen is true
    - On Escape: setIsOpen(false)
    - Clean up listener when menu closes or component unmounts

    **Focus restoration:**
    - Use a useRef for the hamburger button
    - When menu closes (isOpen goes from true to false), return focus to the hamburger button ref

    **Neobrutalist design notes (Claude's discretion):**
    - Hamburger button: p-2 border-[3px] border-foreground bg-surface shadow-brutal hover:shadow-brutal-hover hover:translate-x-[2px] hover:translate-y-[2px] transition-all duration-150
    - This matches the existing neobrutalist button styling in the codebase (bold borders, hard shadows, hover shift)
