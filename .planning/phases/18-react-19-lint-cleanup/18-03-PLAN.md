<objective>
Fix the 1-frame flash when clicking tag filters on blog and project listing pages.

Purpose: Phase 18 moved `setIsTransitioning(true)` from a synchronous ref-during-render pattern into a `useEffect`, which fires after the browser paints. This introduces a visible flash where new filtered content appears at full opacity for one frame before the transition flag kicks in. The fix replaces the manual `isTransitioning` + `useEffect` + `setTimeout` pattern with React 19's `useTransition`, where `isPending` becomes true synchronously (no paint gap) and React defers the content update.

Output: Smooth filter transitions with no flash, zero lint warnings, all tests passing.
</objective>

    2. **Replace the transition state block.** Remove these lines:
       - `const [isTransitioning, setIsTransitioning] = useState(false)`

       - `const filteredKey = [...activeFilters].sort().join(',')`
       - The entire `useEffect` that watches `filteredKey` and sets `isTransitioning`

    3. **Wrap URL updates in startTransition.** In the `updateURL` callback, wrap the `window.history.replaceState` call in `startTransition(() => { ... })`. This makes `isPending` become `true` synchronously when a filter is toggled, before React re-renders with new content. React will defer the re-render, keeping old content visible while `isPending` is true.

       IMPORTANT: `startTransition` alone with `replaceState` will NOT defer the content update because `replaceState` is not a React state update. The actual mechanism: `isPending` goes true synchronously on the `startTransition` call, and since the content update comes from `useSearchParams` re-rendering (triggered by the Suspense boundary detecting the URL change), the opacity-0 class is already applied before the new content paints. The `startTransition` signals to React that the enclosed work is non-urgent.

    4. **Update the return type interface.** Change `isTransitioning: boolean` to `isPending: boolean` in `UseFilteredListResult`. Return `isPending` from the `useTransition` hook directly (renamed from the destructured value if needed for clarity).
