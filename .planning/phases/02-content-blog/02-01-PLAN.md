   ```bash
   npm install velite rehype-pretty-code shiki @rehype-pretty/transformers rehype-slug
   ```

2. Create velite.config.ts at project root with Post collection:
   - Use s.object() with: title, slug, date, updated (optional), description (optional), tags, draft, toc, metadata, excerpt, body
   - Add transform to create permalink and readingTime fields
   - Configure rehype-pretty-code with github-dark-dimmed theme
   - Enable transformerCopyButton with visibility: 'hover'
   - Add rehype-slug for heading IDs
   - Set showLineNumbers on code blocks by default
   - Output to .velite directory, assets to public/static

3. Update next.config.ts for Turbopack-compatible Velite initialization:
   - Use top-level await pattern (NOT VeliteWebpackPlugin)
   - In development: build({ watch: true, clean: false })
   - In production: build({ watch: false, clean: true })
   - Import velite dynamically to avoid ESM issues

4. Update tsconfig.json paths to include @/.velite alias:
   ```json
   "@/.velite": ["./.velite"]
   ```

5. Add .velite to .gitignore (generated files should not be committed)

IMPORTANT: Do NOT use VeliteWebpackPlugin - it breaks Turbopack. Use the top-level await pattern from RESEARCH.md.
