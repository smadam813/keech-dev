- Add `'use client'` directive
- Import `useEffect`, `useLayoutEffect`, `useState` from React
- Define interface `ListingViewCountsProps`:
  - `slugs: string[]` — list of post slugs to fetch counts for
  - `children: (counts: Record<string, number | null>) => React.ReactNode` — render prop pattern
- Implement `ListingViewCounts` component:
  - `useState<Record<string, number | null>>({})` for counts
  - `useLayoutEffect` (runs before paint): read cached counts from localStorage using `views:${slug}` keys (same keys as ViewCounter). If any cached values exist, set them immediately for instant display on return visits.
  - `useEffect`: fetch batch counts from `/api/views?slugs=${slugs.join(',')}`. On success, update state and write each count to localStorage. On failure, `catch(() => {})` — silent failure, cached values remain or counts stay empty object (UX-03 graceful degradation).
  - Return `<>{children(counts)}</>` — render prop passes counts to children
- PostCard stays a server component — the client boundary is this wrapper, not the card itself.

**2. Modify `src/components/blog/post-card.tsx`** — Add optional views prop:
- Add `import { formatViewCount } from '@/lib/views'` (from Plan 01)
- Extend `PostCardProps` interface: add `views?: number | null`
- Update component signature: `export function PostCard({ post, views }: PostCardProps)`
- In the metadata row `<div>`, after the `{post.readingTime} min read` span, add a conditional block:
  ```
  {views != null && (
    <>
      <span aria-hidden="true" className="text-accent font-display font-bold">
        {POST_RUNES.separator.char}
      </span>
      <span>{formatViewCount(views)}</span>
    </>
  )}
  ```

  - API unreachable → `views` is null/undefined → count section omitted (UX-03)

- Existing PostCard rendering and structure remain unchanged. The views section only appends to the metadata row.
