Create a client component for cross-browser scroll-reveal animations using Intersection Observer API.

**Create `src/components/ui/scroll-reveal.tsx`:**
- Client component ('use client')
- Accept children and optional className prop
- Use useEffect with IntersectionObserver to detect when element enters viewport
- Add 'animate-fade-in-up' class when intersection threshold (0.1) is met
- Start with opacity-0 translate-y-5, animate to opacity-100 translate-y-0
- Include motion-safe check via matchMedia for prefers-reduced-motion
- If reduced motion preferred, render children without animation wrapper

**Update `src/app/globals.css`:**
- Keep the fadeInUp keyframe (it's good)
- Remove the scroll-reveal class and @supports (animation-timeline: view()) block entirely
- Add new utility classes for the Intersection Observer approach:
  - `.animate-fade-in-up`: applies the fadeInUp animation
  - `.animate-on-load`: immediate fade-in animation for hero (not scroll-triggered)
- Keep prefers-reduced-motion media query but update selectors

The ScrollReveal component wraps individual items and triggers animation when they scroll into view.
